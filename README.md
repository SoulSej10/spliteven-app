# SplitEven for Android

Download the latest Android app: **[SplitEven.apk](../../releases/latest/download/SplitEven.apk)**

SplitEven splits shared expenses with friends and tracks your own money, on Android and on the web.

- Web app: https://evensplit-eight.vercel.app

## Installing

1. Open the download link on your Android phone and download `SplitEven.apk`.
2. When Android asks, allow installs from this browser or app ("Install unknown apps").
3. Open the downloaded file and tap Install.

Older versions are listed under [Releases](../../releases).
